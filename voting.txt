📑 Product Trade Voting System — Backend Developer Documentation ১. সিস্টেমের কার্যপদ্ধতি (How It Works) ট্রেড সম্পন্ন হওয়া: যখন দুজন ইউজার অ্যাপে সফলভাবে প্রোডাক্ট অদলবদল (Trade/Swap) সম্পন্ন করেন, ব্যাকএন্ড স্বয়ংক্রিয়ভাবে সেই ট্রেডটিকে একটি Community Voting Card হিসেবে হোম ফিডে যুক্ত করে। কমিউনিটি ইউজারদের ভোট দেওয়া: সাধারণ ইউজাররা হোম স্ক্রিনে এসে দুটি প্রোডাক্টের ছবি ও আনুমানিক মার্কেট ভ্যালু দেখে বিবেচনা করবে কার লাভ বেশি হয়েছে এবং "Vote Trader A" বা "Vote Trader B" বাটনে ট্যাপ করবে। সিঙ্গেল ভোট রুল (Single Vote per User): একজন ইউজার একটি নির্দিষ্ট ট্রেডে কেবল একবারই ভোট দিতে পারবে। ভোট দেওয়ার পর ফলাফল উন্মোচন: ভোট দেওয়ার পূর্বে বা পরে মোট ভোট সংখ্যা এবং দুই পক্ষের পার্সেন্টেজ বার (যেমন: Trader A: 42%, Trader B: 58%) লাইভ দেখাবে। ইউজার যেটাতে ভোট দিয়েছে সেটিতে টিকমার্ক এবং হাইলাইট কালার থাকবে। ২. ডাটাবেজ মডেল (Database Schemas) ডাটাবেজে দুটি টেবিল/কালেকশন প্রয়োজন হবে: A. TradeVote (ট্রেড ভোটিং কার্ডের তথ্য) javascript // MongoDB Mongoose Schema Example const TradeVoteSchema = new mongoose.Schema({   tradeId: {     type: mongoose.Schema.Types.ObjectId,     ref: 'Trade',     required: true   },   category: { type: String, default: "Sneakers" }, // e.g. "Trading Cards", "Streetwear"      // Trader A এর আইটেম   itemA: {     name: { type: String, required: true },       // e.g. "Nike Dunk Low 'Panda'"     value: { type: String, required: true },      // e.g. "$180"     image: { type: String, required: true },     traderId: { type: mongoose.Schema.Types.ObjectId, ref: 'User' },     traderName: { type: String, default: "Trader A" }   },      // Trader B এর আইটেম   itemB: {     name: { type: String, required: true },       // e.g. "Air Jordan 1 High"     value: { type: String, required: true },      // e.g. "$210"     image: { type: String, required: true },     traderId: { type: mongoose.Schema.Types.ObjectId, ref: 'User' },     traderName: { type: String, default: "Trader B" }   },   // ভোটের গণনা   votesA: { type: Number, default: 0 },   votesB: { type: Number, default: 0 },   totalVotes: { type: Number, default: 0 },      isActive: { type: Boolean, default: true },   completedAt: { type: Date, default: Date.now } }, { timestamps: true }); B. UserVoteLog (কে কোন ট্রেডে ভোট দিয়েছে তার হিসাব) উদ্দেশ্য: একজন ইউজার যেন বারবার ভোট দিয়ে ফলাফল ম্যানিপুলেট করতে না পারে। javascript const UserVoteLogSchema = new mongoose.Schema({   userId: {     type: mongoose.Schema.Types.ObjectId,     ref: 'User',     required: true   },   tradeVoteId: {     type: mongoose.Schema.Types.ObjectId,     ref: 'TradeVote',     required: true   },   votedOption: {     type: String,     enum: ['A', 'B'],     required: true   } }, { timestamps: true }); // ডুপ্লিকেট ভোট রোধ করতে কম্পাউন্ড ইউনিক ইনডেক্স UserVoteLogSchema.index({ userId: 1, tradeVoteId: 1 }, { unique: true }); ৩. REST API স্পেসিফিকেশন (Endpoints) ১) হোম স্ক্রিনের জন্য ভোটিং ফিড ফেচ করা Endpoint: GET /api/v1/trades/votes/feed Headers: Authorization: Bearer <TOKEN> (অপশনাল বা রিকোয়ার্ড) Query Params: ?limit=10&page=1 Backend Logic: ডাটাবেজ থেকে অ্যাক্টিভ রিসেন্ট ট্রেডগুলো ফেচ করবে। বর্তমান লগইন করা ইউজার যদি কোনো ট্রেডে ভোট দিয়ে থাকে, তবে তার রেসপন্সে hasVoted: true এবং votedOption: "A" বা "B" রিটার্ন করবে। Response (200 OK): json {   "success": true,   "data": [     {       "_id": "65f123abc456...",       "category": "Sneakers",       "timeAgo": "Completed 2h ago",       "itemA": {         "name": "Nike Dunk Low 'Panda' (DS)",         "value": "$180",         "image": "https://images.unsplash.com/photo-1595950653106-6c9ebd614d3a"       },       "itemB": {         "name": "Air Jordan 1 High 'Shadow 2.0'",         "value": "$210",         "image": "https://images.unsplash.com/photo-1584735935682-2f2b69dff9d2"       },       "votesA": 14,       "votesB": 36,       "totalVotes": 50,       "percentageA": 28.0,       "percentageB": 72.0,       "hasVoted": false,       "votedOption": null     }   ] } ২) ভোট সাবমিট করা Endpoint: POST /api/v1/trades/votes/:id/cast Headers: Authorization: Bearer <TOKEN> (লগইন রিকোয়ার্ড) URL Param: :id (TradeVote আইডি) Request Body: json {   "option": "A" // বা "B" } Backend Controller Implementation (Node.js/Express Example): javascript exports.castVote = async (req, res) => {   try {     const tradeVoteId = req.params.id;     const userId = req.user.id; // JWT থেকে     const { option } = req.body;     if (!['A', 'B'].includes(option)) {       return res.status(400).json({ success: false, message: "Invalid option. Must be 'A' or 'B'" });     }     // ১. চেক করুন ইউজার আগেই ভোট দিয়েছে কিনা     const existingVote = await UserVoteLog.findOne({ userId, tradeVoteId });     if (existingVote) {       return res.status(409).json({         success: false,         message: "You have already voted on this trade!"       });     }     // ২. অ্যাটমিক ইনক্রিমেন্ট (Concurrency safe)     const incField = option === 'A' ? { votesA: 1 } : { votesB: 1 };          const updatedTrade = await TradeVote.findByIdAndUpdate(       tradeVoteId,       {         $inc: { ...incField, totalVotes: 1 }       },       { new: true }     );     if (!updatedTrade) {       return res.status(404).json({ success: false, message: "Trade vote not found" });     }     // ৩. ইউজারের ভোটের রেকর্ড সেভ     await UserVoteLog.create({       userId,       tradeVoteId,       votedOption: option     });     const pctA = Math.round((updatedTrade.votesA / updatedTrade.totalVotes) * 100);     const pctB = 100 - pctA;     return res.status(200).json({       success: true,       message: "Vote cast successfully",       data: {         tradeVoteId: updatedTrade._id,         votesA: updatedTrade.votesA,         votesB: updatedTrade.votesB,         totalVotes: updatedTrade.totalVotes,         percentageA: pctA,         percentageB: pctB,         hasVoted: true,         votedOption: option       }     });   } catch (error) {     // Duplicate Key Error (MongoDB E11000) হ্যান্ডলিং     if (error.code === 11000) {       return res.status(409).json({ success: false, message: "Duplicate vote detected." });     }     return res.status(500).json({ success: false, message: error.message });   } }; ৪. সিকিউরিটি ও বিজনেস রুলস (Rules & Validations) Self-Voting Prohibition (ঐচ্ছিক কিন্তু স্ট্যান্ডার্ড): ট্রেডে অংশগ্রহণকারী দুই ইউজার (traderId) নিজেদের ট্রেডে ভোট দিতে পারবে না, যাতে ভোটিং সম্পূর্ণ নিরপেক্ষ (fair community review) হয়: javascript if (trade.itemA.traderId.equals(userId) || trade.itemB.traderId.equals(userId)) {   return res.status(403).json({ message: "Traders cannot vote on their own trade." }); } ডাবল ভোট ঠেকানো: UserVoteLog টেবিলের কম্পাউন্ড ইউনিক ইনডেক্স ব্যাকএন্ড লেভেলে একাধিক ভোট পড়া ১০০% আটকে দেবে। পার্সেন্টেজ ক্যালকুলেশন হ্যান্ডলিং: মোট ভোট যখন 0 থাকবে, তখন পার্সেন্টেজ যেন ক্র্যাশ না করে (50% / 50% দেখাবে)। ৫. ফ্লাটার অ্যাপে ডাটা কানেক্ট করার স্টেপ বর্তমানে ফ্লাটার অ্যাপের HomeController-এ এটি লোকাল লিস্ট (recentTrades) দিয়ে মক করা আছে: এপিআই রেডি হলে GET /api/v1/trades/votes/feed কল করে recentTrades লিস্টে ডাটা অ্যাসাইন করতে হবে। বাটন ট্যাপ করলে voteOnTrade(tradeId, option) ফাংশনটি লোকাল স্টেট আপডেটের সাথে সাথে POST /api/v1/trades/votes/:id/cast এপিআই কল করবে। আপনার ব্যাকএন্ড ডেভেলপার এই ডকটি পেলেই সরাসরি ডাটাবেজ মডেল এবং এপিআই দুটি ডেভেলপ করতে পারবে!
