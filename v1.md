📌 Testing Guide for Developers
1. Real-Time Bid Testing via Socket.io
Connect to socketHelper.ts and emit a place-bid event:

json
{
  "streamId": "65b98f21bc90a8274567abcd",
  "auctionItemId": "65b98f21bc90a8274567abef",
  "bidAmount": 150,
  "bidderId": "65b98f21bc90a8274567ab00"
}
Expected Reaction:
Emits new-bid to everyone in the room containing the updated bid and highest bidder info.
If two sockets emit the same bid concurrently, the database will atomically reject the slower bid and return a secure bid-error to that user's socket only.
